# Vigilantes da Colina Kids

Site responsivo e estático do Clube de Aventureiros Vigilantes da Colina Kids — Piracicaba/SP.

## Estrutura

- `index.html` — página principal
- `css/style.css` — estilos e responsividade
- `js/script.js` — menu mobile, botão voltar ao topo e formulário por e-mail

## Como publicar

1. Extraia o ZIP.
2. Abra `index.html` para testar localmente.
3. Antes de publicar, altere no `index.html`:
   - número do WhatsApp;
   - e-mail;
   - textos da agenda;
   - informações de contato.
4. Envie a pasta para uma hospedagem de site estático.

## Sem banco de dados

O projeto não usa banco de dados, PHP ou servidor. O formulário usa `mailto:` e abre o aplicativo de e-mail do visitante.

## Fotos

Os blocos da galeria são placeholders. Você pode substituir cada `photo-placeholder` por imagens reais do clube.
